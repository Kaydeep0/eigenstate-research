Browser demo mirrors helixhash 1.0: each entry is append(bytes) of a JSON observation payload; the tip hash covers index, payload, timestamp, and previous hash (no PT / Fibonacci / Crossing in the protocol). Altering any payload breaks verify(). The private engine uses the same primitive on its vault and may commit the tip to Base when gates pass. On-chain cadence is not continuous — see the On-Chain Proof Index. Full API: HELIXHASH.md.
